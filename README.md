## 每道题的写法

每个 `.cpp` 文件包含五部分，顺序固定：

1. **题目**：链接、难度、一句话描述（含输入输出约束）
2. **思路**：从暴力解法到最优解法的演进，以及为什么能优化
3. **复杂度**：时间 / 空间，并说明瓶颈在哪
4. **易错点**：边界条件、下标、溢出
5. **面试追问**：这题还能怎么变形？换输入会怎样？

参考 `src/0001_two_sum.cpp`。

## 如何运行

```bash
make                              # 编译全部题解
make run NAME=0001_two_sum        # 编译并运行单题
make clean                        # 清理 build/
```

只依赖 clang++ / g++ 和 make，不需要额外安装。
